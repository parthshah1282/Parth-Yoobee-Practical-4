Student Grading System 

This is a basic Student Grading System made using Python classes and methods. It helps to:

- Create student records
- Add grades for each student
- Calculate average marks
- Convert average to a letter grade (A–F)
- Show a full report

Features:

- Object-oriented code using class student
- Easy functions to add grades and display results
- Letter grade system based on average score

How it works:

- A student object is created with a name.
- You add grades using add_grades().
- The program calculates the average using get_avg().
- It converts the average into a letter grade using get_letter_grade().
- The show_report() method prints all details.
